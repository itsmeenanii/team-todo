# Team-Todo 🚀

**A powerful collaborative task management platform that brings teams together through shared goals, personal productivity, and intelligent notifications.**

Team-Todo is a full-featured group task management application that combines the simplicity of a to-do list with powerful collaboration features. Built with Django and modern web technologies, it enables teams to stay organized, track progress, and celebrate achievements together.

## ✨ Key Features

- **🔐 Secure Authentication**: Login with email/password or mobile OTP
- **👥 Group Tasks**: Auto-assigned daily tasks visible to all team members
- **👤 Personal Tasks**: Private to-do items visible only to you
- **🎯 Admin Control**: Add/remove members like WhatsApp group management
- **📊 Progress Dashboard**: Real-time completion status of all members
- **🔔 Smart Reminders**: Automatic notifications for pending tasks via email & push
- **📱 Mobile Ready**: Fully responsive design works on all devices

## 🎯 Perfect For

- **Remote Teams**: Stay aligned on daily goals
- **Study Groups**: Track project progress together
- **Family Tasks**: Manage household responsibilities
- **Small Businesses**: Monitor team productivity
- **Classrooms**: Assign and track student tasks

## 💡 Why Team-Todo?

Unlike traditional to-do apps, Team-Todo focuses on **collaboration first**:
- 👀 **Visibility**: See who's done what at a glance
- 🤝 **Accountability**: Team members know when tasks are pending
- 🏆 **Motivation**: Healthy competition through completion tracking
- ⚡ **Efficiency**: Automated daily tasks reduce management overhead
- 🔄 **Flexibility**: Mix of group and personal tasks in one platform
